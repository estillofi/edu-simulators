# edu-simulators — инструкция агенту

Репозиторий тренажёров онлайн-школы Корифей с живой аналитикой для учителя. Сайт: https://estillofi.github.io/edu-simulators/ (GitHub Pages). Локальная копия (git): `~/Documents/Корифей/02_Генерация_уроков/Тренажёры_3кл/edu-simulators/`. Push — по SSH `git@github.com:estillofi/edu-simulators.git`, перед push — `git pull --rebase --autostash` (в репо пишут другие сессии; чужие файлы не трогать).

Скилл для сборки: `kori-trainer` (тренажёры), `kori-lab` (лабораторные с приборами). Спека для разработки: `docs/SPEC-dev.md`. История и решения: `docs/HANDOFF.md`.

## Что такое «тренажёр с живой аналитикой»

```
ученик: тренажёр (index.html) ── kori-trace ──► сервер класса (server/) ──► табло учителя (teacher/)
        Кори-компаньон                         SQLite events            три сигнала + измерения
```

Без сервера (GitHub Pages) тренажёр работает, события остаются у ученика. Живой эфир — только когда страница открыта с сервера класса по ссылке учителя `?c=<класс>&s=<токен>`.

## Общие части — подключать, не копировать

| Файл | Назначение |
|---|---|
| `shared/kori-trace.js` | журнал событий v1: `KoriTrace.init({trainer})`, `item({item_id, skill, node, level, template})` → `.attempt({correct, answer, misconception})`, `.hint(n)`, `.end()` |
| `shared/kori-companion.js` + `shared/kori/*.webp` | Кори: `mount`, `welcome`, `hint(text)`, `correct({streak, hard, levelUp})`, `wrong()` (молчит) |
| `shared/kori-algebra.js` | разбор/сравнение буквенных выражений (`parse`, `show`) |
| `server/server.mjs`, `schema.sql`, `signals.mjs` | приём событий, SQLite, SSE, три сигнала, метрики Аббакумова |

| `teacher/index.html`, `tokens.html` | табло и ссылки с токенами |

## Рецепт нового тренажёра (по образцу `math-7/expressions/`)

1. **Бриф:** тема/МЭО-урок, навыки (3–4), уровни А/Б/В, узел и ID заблуждений из таблицы методиста (лист «Типичные ошибки», служебный код); нет в таблице — локальный код `(local)`.
2. **Банк — шаблоны, не задания:** функция со случайными параметрами → `{expr|вопрос, ответ, hint3, extra:[{code, ответ-с-ошибкой}]}`. Чужие сборники дословно не публиковать: структура и уровни — их, числа — свои.
3. **Ошибки — моделями:** сравнить ответ с ответами «по ошибочному правилу»; общий фолбэк — «проверь числами: при x = 2 исходное равно …, твоё — …».
4. **Самопроверка банка (обязательно):** сотни заданий; каждое принимает свой ответ и узнаёт каждую ловушку своим ID. Ноль отказов.
5. **Подключить** `kori-trace`, `kori-companion`; недописанный ответ — не попытка; фокус после «Верно» не переносить (второй Enter = «Дальше»).
6. **Проверить:** `node server/server.mjs` → `node server/simulate.mjs --class DEMO-7A --n 25 --minutes 3 --speed 4` → табло `/teacher/?c=DEMO-7A`; ученик по ссылке с токеном появляется ≤ 5 с; ширина 375 px; светлая/тёмная тема.
7. **Выложить:** карточка в `index.html`, раздел в `README.md`, коммит с `Co-Authored-By`, push.

## Правила Кори (решение Дениса)

Машет при входе; говорит только подсказками (3 ступени: вопрос → правило → шаг этого задания); на верный ответ — поза без слов (×5 подряд — кубок, новый уровень — «ура»); на ошибку не реагирует; кнопка «Тише». Без очков и рейтингов.

## Измерения (Аббакумов, «Психометрика в EdTech», гл. 7–9)

Супербалл задания 0..1 (1 — с первой попытки без подсказок; штраф −0,25 за попытку/подсказку — наш параметр). Посильность — среднее по заданию; успеваемость — среднее по ученику (текущая и накопительная); дельта = супербалл − посильность (±0,1); прогресс и скорректированный прогресс = прогресс × успеваемость. Категории: < 0,45 fru · 0,45–0,70 sub · 0,70–0,90 opt · ≥ 0,90 bor. Доверие: n ≥ 15 и se ≤ 0,075.

Сигналы табло (пороги в `RULES`, гипотезы): **застрял** (3 ошибки подряд в навыке / одна ошибка 2 раза из 5 / > 2 мин без продвижения), **угадывает** (≥ 2 быстрых < 5 с неверных из 4 / подсказка < 6 с дважды), **освоил** (BKT ≥ 0,95 или 3 подряд со score 1 на Б/В; ≥ 4 заданий; не угадывает).

## Приватность

Токены вместо имён; имена — только в браузере учителя. Наружу — агрегаты от 3 учеников. `server/data/` не публикуется. Боевой сервер — РФ + согласия родителей. Без камер и распознавания эмоций.
