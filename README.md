# edu-simulators

Интерактивные тренажёры онлайн-школы Корифей. Каждый тренажёр — одна HTML-страница: работает в браузере, без установки и без сервера.

**Сайт:** https://estillofi.github.io/edu-simulators/

## Тренажёры

| Тренажёр | Предмет, класс | Ссылка |
|---|---|---|
| Площадь на клетках | Математика, 3 класс | [math-3/area](https://estillofi.github.io/edu-simulators/math-3/area/) |
| Плотность твёрдого тела | Физика, 7 класс | [physics-7/density](https://estillofi.github.io/edu-simulators/physics-7/density/) |

### Площадь на клетках

Три уровня, по одной фигуре на уровень — одинаковые у всех учеников:

- **Базовый** — прямоугольник 8 × 3 см.
- **Повышенный** — ступенчатая фигура: разрезать на прямоугольники.
- **Сложный** — параллелограмм: отрезать треугольник по пунктиру и переставить, получится прямоугольник.

Ученик может закрашивать клетки, открывать подсказки (вопрос → подсказка → пример) и выбирать единицу: см или см². Тренажёр распознаёт типичные ошибки: периметр вместо площади, сумму сторон, клетки только у края, «см» вместо «см²», убеждение, что перестановка части меняет площадь.

### Плотность твёрдого тела

Виртуальная лабораторная работа из ФРП. На столе учебные рычажные весы с разновесом, мензурка с водой и три тела: А и Б из одного вещества, но разного размера; Б и В одного размера, но из разных веществ.

- **Прогноз до опыта:** у какого тела плотность больше. После опыта страница сравнивает прогноз с результатом.
- **Масса:** тело на одну чашку, гири на другую, равновесие видно по стрелке в лупе.
- **Объём погружением:** цена деления, уровень по нижнему краю мениска (в лупе двигается глаз), V = V₂ − V₁.
- **Плотность:** ρ = m : V, вещество по таблице, перевод в кг/м³.

Ответы не показываются — тренажёр объясняет ошибку: сумма гирь без равновесия, 500 мг как 5 г, цена деления = 20, чтение мениска сверху, V = V₂, ρ = V : m. Подсказки по шагам: вопрос → подсказка → пример. У каждого ученика свои размеры тел и уровень воды. Внизу страницы — свёрнутый блок «Для учителя» с журналом действий ученика.

Исходник собирается скиллом `kori-lab` поверх `anatomy`: `node examples/density/build.mjs --standalone --out <путь>/index.html`.

### Степень с натуральным показателем

МЭО-урок 1.3 (уроки ФРП 10–14). Пять тренажёров на одной странице, задания одинаковые у всех учеников:

1. **Что такое степень** — 2⁵ против 5², степень как повторное умножение.
2. **Минус и степень** — −2⁴ и (−2)⁴, знак при отрицательном основании.
3. **Большие числа** — 3,2 · 10⁵: сдвиг запятой вместо «дописать нули».
4. **Умножение степеней** — 2³ · 2²: множители считают, показатели складываются.
5. **Уравнения** (дополнительно) — x³ = −8, x² = 25, x⁴ = −16.

В каждом тренажёре сначала прогноз (ловушка урока), потом модель — она открывается после прогноза, — потом задания с разбором ошибок и тремя подсказками.

## Структура

```
index.html            каталог тренажёров
math-3/area/          Площадь на клетках
  index.html
physics-7/density/    Плотность твёрдого тела
  index.html
math-7/power/         Степень с натуральным показателем
  index.html
```

Новый тренажёр — новая папка `<предмет>-<класс>/<тема>/index.html` и строка в таблице выше и в `index.html`. Имена папок латиницей, без пробелов: они становятся частью адреса.

## Данные

Тренажёры ничего не отправляют: ответы видны только на устройстве ученика и пропадают при закрытии вкладки. Персональные данные не собираются. Лабораторная по физике запоминает в браузере только номер варианта, чтобы после перезагрузки остались те же тела.
