## Решения Дениса

- Прототипы — на его компьютере (MVP), потом передача разработке в LMS и практику Кори; сверка через Доску.
- Кори: машет при входе, говорит только подсказками, на ошибку не реагирует; без очков и рейтингов; на верный — поза без слов.
- Задания одинаковые у всех там, где класс обсуждает; для повторения — перемешанный банк и уровни.
- Психометрика — задел базы: сырые события без потерь, метрики по Аббакумову.
- Источник заблуждений — таблицы методистов (`Алгебра 7 — онлайн-школа, ред. 2`, Drive `06_Методистам для сверки`).

## Факты, проверенные в сессии

- Банк «Скобок»: 720 сгенерированных заданий — 0 отказов на верный ответ; «Степени-тренировки»: 390 — 0.
- Табло: 25 ботов → все три сигнала; живой ученик появляется на табло, супербалл считается.
- Книга не задаёт штрафы супербалла (−0,25 — наш параметр) и формулу se в прототипе считается только через n.
